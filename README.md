# Приёмка+ — прототип модуля претензий ВЭД

Прототип для проверки одной гипотезы: если система сама собирает пакет документов по претензии к поставщику и явно показывает, чего не хватает, специалист ВЭД соберёт пакет за ≤30 минут активной работы.

- **Прототип:** https://supplier-claim-manag-qxxx.bolt.host
- **Исследование, гипотеза и требования:** https://github.com/barbaraNik/requirements-discrepancy

## Что умеет

- Лента претензий со статусом пакета: «Не хватает: N», «Ожидает документы», «Пакет полный», «Пакет готов».
- Карточка претензии: позиции с расхождениями, чек-лист документов, загрузка и просмотр файлов, запрос недостающего у склада, продакт-менеджера или сервисной службы.
- Кнопка «Пакет готов» активна, только когда все пункты закрыты или запрошены.

Сознательно вне скоупа: письмо поставщику, отправка, сроки претензий, суммы, авторизация, база данных.

## Данные

Кейсы смоделированы на основе типовых ситуаций из практики ВЭД, данные обезличены, компания условная. Данные хранятся в приложении: после обновления страницы прототип возвращается к исходным четырём претензиям.

## Как собран

Сгенерирован в Bolt по промпту, составленному из бизнес-правил проекта (BR-02, BR-06, BR-08 в редакции для прототипа). Стек: React, TypeScript, Vite, Tailwind.

```bash
npm install
npm run dev
```
